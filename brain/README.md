# NPC 두뇌 (직접 학습한 신경망)

NPC가 말을 알아듣는 데 쓰는 딥러닝 모델이다. 외부 AI 서비스 없이 브라우저 안에서 돈다.

- 입력: 문장을 음절 n-gram, 단어, 자모 n-gram으로 쪼갠 뒤 해시(4096칸)로 바꾼다.
- 구조: 임베딩(48차원) → 은닉층 96 → 은닉층 96 → 의도 70종 + 감정 3종(긍정·부정·보통).
- 학습 데이터: 약 11만 7천 문장 (반말·존댓말, 줄임말, 오타, 띄어쓰기 생략, 상관없는 앞뒤 말, 비슷한 말 바꾸기, 어순 바꾸기).
- 3차: 2차 모델과 3차 모델을 선생으로 두고 지식 증류해서 모델 하나로 합쳤다 (`distill.py`).
- 크기: int8 양자화해서 `npc-brain.js` 약 308KB. 한 문장 판단에 1ms 이하.

## 성능 (학습에 쓰지 않은 문장)

| 시험지 | 문장 수 | 1차 | 2차 | 3차(현재, 증류) |
| --- | --- | --- | --- | --- |
| test2 | 137 | 85.4% | 94.9% | 96.4% |
| test4 | 123 | 74.0% | 89.4% | 87.8% |
| test6 | 123 | 73.0% | 87.0% | 87.8% |

test3, test5는 앞 모델이 틀린 표현을 보고 데이터를 보강했기 때문에 점수가 부풀려져 참고용이다. test6은 3차 데이터 설계를 마친 뒤 학습 전에 쓴 시험지다.
합성 데이터만으로는 새 문장 기준 88~90% 근처에서 멈춘다. 더 올리려면 실제 대화가 필요해서, 대화창에 "어색해요" 버튼을 넣었다.
플레이어가 누른 문장은 관리자 창의 "어색한 NPC 대답"에 모이고, "학습용으로 복사"로 꺼내 `gen_data3.py`에 넣으면 된다.

대화 엔진은 먼저 규칙으로 답해 보고, 규칙이 못 알아들었거나 엉뚱하게 답했을 때 모델이 읽은 의도로 다시 답한다.
위기 표현은 규칙과 모델 둘 중 하나만 잡아도 반응하고 상담 전화를 안내한다.

## 다시 학습하기

```bash
pip install torch numpy
cd brain
python3 test_set.py; python3 test2.py; python3 test3.py; python3 test4.py; python3 test5.py; python3 test6.py
python3 gen_data3.py                         # 학습 데이터 생성 (gen_data.py → gen_data2.py → gen_data3.py 순서로 확장)
H=96 python3 train.py 4096 48 22 test2.json  # npc-brain.js 생성
# (선택) 여러 모델을 증류해서 하나로: python3 distill.py 모델A.js,모델B.js 22
cp npc-brain.js ../npc-brain.js
```

말이 안 통하는 문장이 있으면 `gen_data3.py`의 해당 의도 목록에 비슷한 문장을 더하고 다시 학습하면 된다.
